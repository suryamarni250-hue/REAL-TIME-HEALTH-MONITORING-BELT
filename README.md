REAL-TIME HEALTH MONITORING BELT WITH EMERGENCY ALERT SYSTEM

1) Project Overview
This project is an IoT-based wearable health monitoring system using ESP32, MAX30102, MPU6050, GPS, and Firebase.

The system monitors:
- Heart Rate
- SpO₂
- Fall Detection
- Emergency Alerts
- GPS Location Tracking

2) Features
- Real-time health monitoring
- Fall detection using MPU6050
- GPS location tracking
- Firebase cloud integration
- Live website dashboard
- Emergency button alert
- Buzzer alarm system

 3) Hardware Used
- ESP32
- MAX30102
- MPU6050
- NEO-6M GPS
- Push Button
- Buzzer

4) Software Used
- Arduino IDE
- Firebase Realtime Database
- HTML/CSS/JavaScript

5) Website Dashboard
Displays:
- Heart Rate
- SpO₂
- Emergency status
- Live GPS location
